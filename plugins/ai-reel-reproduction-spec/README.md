# AIリール再現仕様書

公開されているInstagram Reels、TikTok、YouTube ShortsのアカウントURLから、伸びる機構を証拠ベースで抽出し、コピーではないオリジナルの「再現仕様書」を作るCodexプラグインです。各アカウント専用の再現モデルと、複数アカウントで検証された横展開用の市場知能を分離して、フック・台本・映像・音声・字幕・CTAを継続更新できます。

## 入力

最低限、公開アカウントのURLを1つ指定します。動画ファイル、投稿別数値、Instagram Insightsが追加されるほど分析精度と予測信頼度が上がります。

## 出力

- 証拠範囲と信頼度
- 伸びた投稿／伸びない投稿の比較
- 市場ニーズとアカウント資産の交点
- 転用できる成長機構とコピー禁止要素
- オリジナル企画10本
- 最優先企画の台本、画面テキスト、映像・音声・編集仕様
- 低位／基準／高位の反応予測
- 検証計画と追加で必要なデータ
- 分析を重ねて更新される6要素別の市場パターン

## 使い方

新しいCodexタスクで、次のように依頼します。

```text
$reconstruct-ai-reel-spec
この公開アカウントURLを分析して、AIリールの再現仕様書を作ってください。
URL: https://www.instagram.com/example/
```

同じアカウント専用の再現モデルを更新する場合：

```text
$learn-ai-reel-market
この公開アカウントを取り込み、このアカウント専用の再現モデルを更新してください。
URL: https://www.instagram.com/example/
```

1アカウントだけでも、その同じアカウント専用の再現モデルを作れます。別アカウントへの反映や共通ルール化には、最低3つの独立アカウントで同じ機構が確認される必要があります。学習結果は実行ワークスペースの`.ai-reel-intelligence`へ保存され、次回の再現仕様書で参照されます。これはCodex基盤モデルの再学習ではありません。

再現対象は成長機構です。実在クリエイターの人格、声、キャラクター、台本、映像、音楽、ジョーク、ショット順のコピーや、プラットフォームのアクセス制限回避は行いません。
