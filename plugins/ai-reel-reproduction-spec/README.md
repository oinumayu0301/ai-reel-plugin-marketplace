# AIリール再現仕様書

公開されているInstagram Reels、TikTok、YouTube ShortsのアカウントURLから、伸びる機構を証拠ベースで抽出し、コピーではないオリジナルの「再現仕様書」を作るCodexプラグインです。

## 入力

最低限、公開アカウントのURLを1つ指定します。動画ファイル、投稿別数値、Instagram Insightsが追加されるほど分析精度と予測信頼度が上がります。

## 出力

- 証拠範囲と信頼度
- 伸びた投稿／伸びない投稿の比較
- 市場ニーズとアカウント資産の交点
- 転用できる成長機構とコピー禁止要素
- オリジナル企画10本
- 最優先企画の台本、画面テキスト、映像・音声・編集仕様
- 低位／基準／高位の反応予測
- 検証計画と追加で必要なデータ

## 使い方

新しいCodexタスクで、次のように依頼します。

```text
$reconstruct-ai-reel-spec
この公開アカウントURLを分析して、AIリールの再現仕様書を作ってください。
URL: https://www.instagram.com/example/
```

再現対象は成長機構です。実在クリエイターの人格、声、キャラクター、台本、映像、音楽、ジョーク、ショット順のコピーや、プラットフォームのアクセス制限回避は行いません。
